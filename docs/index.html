🌱 RainBird Web App

A responsive, multi-client web interface for the Rain Bird ESP-ME3 — built to stay fast and honest on top of a notoriously flaky single-connection controller.

Quick Start

Run locally

python3 server.py            # serves on http://localhost:8000
# open the page, then Settings → enter controller IP + password (or Scan)

Deploy (Docker)

docker compose up -d --build # config persists in ./config (mounted volume)

Find the controller

# Settings → Scan. It TCP-sweeps the /24, filters by Rain Bird MAC (50:06:F5),
# and confirms each candidate with a real protocol handshake.
